## About me

I study Computer Science at Hochschule Bochum and work part-time in Identity & Access Management, where I solve access and provisioning issues for Bayer in SailPoint IdentityNow.

I like taking things apart to understand how they work. That's why I built a computer from a single NAND gate all the way up to a compiler and an operating system.

<br>
